# Pakistan On Moving World

A scroll-driven 3D journey across six Pakistani cities — Islamabad, Karachi,
Lahore, Peshawar, Gwadar and Skardu — on a single turning Earth.

**Live:** https://pakistan-on-moving-world.vercel.app

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Built with

React, Three.js, Vite and TypeScript. Deployed on Vercel.
